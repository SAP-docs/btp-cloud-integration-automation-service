# Uploading a File in a Task

This section explains how to upload a certificate file to a task so it can be used by other tasks/systems within a scenario.



## Procedure

1.  In a file upload task under the *My Inbox* tile, click *Browse*.

2.  Search and select an SAP S/4HANA Certificate to upload.

    > ### Note:  
    > -   The uploaded file is scanned for malware.
    > -   The supported file formats are JSON, XML, CSV, TXT, CERT, PKCS12, and PEM.
    > -   The maximum allowed file size for upload is 1 MB.

3.  Once done, click *Task Completed*.
